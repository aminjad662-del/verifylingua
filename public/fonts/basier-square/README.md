# Basier Square Commercial Font Assets

Place your licensed Basier Square font files here:
- `BasierSquare-Regular.woff2` (or `.otf` / `.ttf`)
- `BasierSquare-Medium.woff2` (or `.otf` / `.ttf`)
- `BasierSquare-SemiBold.woff2` (or `.otf` / `.ttf`)
- `BasierSquare-Bold.woff2` (or `.otf` / `.ttf`)

The font stack in `app/globals.css` will automatically detect and serve these files, falling back to local system installations (`local("Basier Square")`) and the metric-compatible General Sans font.
